# SpotifyCraft

Un clone open-source d'interface musicale type Spotify, basé sur Vite + React + TypeScript.
Ce dossier est une ossature de départ : la structure de navigation, le thème sombre et
le squelette du lecteur sont en place. Il reste à brancher une source de métadonnées
(Deezer / Spotify Web API), la lecture audio et les playlists.

## Démarrage

```bash
npm install
npm run dev        # http://127.0.0.1:5184
```

Sur macOS, vous pouvez aussi **double-cliquer sur `Démarrer SpotifyCraft.command`**.

Autres commandes :

```bash
npm run typecheck  # vérification TypeScript
npm run build      # build de production dans dist/
npm run preview    # sert dist/
```
